# DualSense glyphs (#694)

Replacement images for the 360 button glyphs, keyed by the hash of the guest bytes of the
texture they replace (`LMA_TEX_LOG`), 64x64 RGBA as the originals: drawn by `tools/gen_glyphs.py`
(no copied artwork). START, BACK, LS and the d-pad glyphs are still to be found; Y came from the squad screen, X from the pre-match screen.
